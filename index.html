Here are some of my projects.

  • Laughbuster Video

    HTML5, CSS3 (Flexbox, Grid, responsive design), JavaScript (ES6+), Fetch API, OMDb API

    Laughbuster Video — A retro-themed video rental site built with vanilla HTML, CSS, and JavaScript. Features a live movie search powered by the OMDb API, a scrollable "Popular Hits" carousel, and a searchable/sortable candy shop page. All without any frameworks.

  • NovaReach: Space Explorer

    React, Vite, Axios, NASA APOD API

    An interactive React app that pulls live daily astronomy photos from NASA's APOD API, with search, sort, and on-demand refresh. Built with React hooks and Axios, it demonstrates async data fetching, derived state, and clean conditional rendering.

  • Dad Supply Co.

    React, React Router JavaScript, CSS3, Vite, LocalStorage

    A fully functional React e-commerce experience built for dad life, because managing state is hard, but managing a cart full of questionable dad gear shouldn’t be. Features dynamic cart management, quantity controls, persistent storage, routing, and real-time subtotal calculations. No assembly instructions required.
